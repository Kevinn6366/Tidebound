# Web 前端与通信迁移规格

更新：2026-09-14。用户纠正上一版的裁剪范围：**原对话框和已经写好的设置功能全部保留，对话接口放到根目录 backend，暂不实现对话业务逻辑。**

## 当前结构

- `webfrontend/src/gwc/`：恢复的完整原界面、资源管理、所有设置页签、立绘与剧本编辑器。原 JSX 结构和 UI 处理保留；主对话、记忆整理、剧情推演和剧本生成中的旧模型执行已移除。
- `webfrontend/src/App.tsx`：挂载完整原界面的入口，取代上一轮的简化标题、对话和视觉设置页面。
- `webfrontend/src/services/`：新增 TypeScript 对话客户端与同源请求适配。后端 501 不能被原设置组件当作保存或执行成功。
- `backend/chat.py`：对话输入模型、应用调用接口与空实现，不依赖 FastAPI，不执行 LLM、上下文、记忆、工具或会话编排。
- `backend/ui_store.py`：开发预览的设置、界面存档与媒体文件访问，按浏览器 Cookie 分目录；不是长期业务 Session 或 MySQL 持久化实现。
- `webapp/`：FastAPI 组装、对话适配、设置/资源通信路由和静态资源读取。
- `webfrontend/legacy/`：保留的原始迁移参考，不进入新入口或静态发布。与 `src/gwc/` 不同，这里保持上游原版以便对照。
- `legacy/gwcpro/`：从根目录 `gwcpro/` 整体迁入，旧后端模型及其他业务保持原样；已迁出的展示入口仍保留迁移注释。

新增 Python 和 TypeScript 有类型及中文文档。恢复的上游 JSX/JS 按触及范围改造，未做无关全量重写；新增 TS 严格检查，恢复的 JS 检查语法与未定义标识符，第三方打包库不纳入业务 lint。

## 对话行为

原来的 START、CONTINUE、对话输入框、附件、快捷栏、历史面板及存读档面板均保留。输入和发送可以操作，发送调用 `POST /api/chat/messages`，再由 `webapp/chat.py` 调用 `backend/chat.py`。

请求只包含正文和附件，不包含前端拼装的模型历史、system prompt 或 API Key。当前空实现返回 HTTP 501 与 `chat_not_connected`，前端显示后端提示、恢复按钮状态，保留草稿和附件；不伪造 assistant 回复，也不保存为已经完成的对话。

用户保留了旧界面中的存档和历史入口，但这不代表 Tidebound 的业务 Session、管理员回退或停止协议已经实现。没有模型执行，原前端桥接、桌宠和执行结果轮询不启动。

## 设置与资源

保留视觉设定、文本互动、声音设定、剧本角色、模型接口、数据管理、插件模组、技能控制台、知识库、账号安全、登录定制、关于系统，以及原 BOT、立绘与剧本编辑器入口。

外观、文本参数、快捷键、角色配置、音频/背景/模型上传、登录外观与插件数据继续通过原控件操作。预览设置和资源保存于 `data/ui-preview/<浏览器标识>/`，刷新后可读。这个目录不进入版本控制，不读取旧账号数据。

HTTP Cookie 是开发预览的数据范围标识，不代表登录或管理员认证。客户端不能通过旧 mirror_id 路径读取其他浏览器数据；拒绝路径越界及跨来源写入，开发 Vite 来源单独允许。文件原子写入，不解压或执行上传内容。

账号管理、技能执行、知识库构建、模型安装、QQ Bot 等依赖尚未迁移后端的入口和配置仍保留，但后台动作返回未接入。这些功能的保留是源代码与界面的保留，不伪造相应服务已经运行。导出当前预览备份只读取本浏览器，不枚举旧用户。

## 启动与验证

依旧使用 `uv run uvicorn webapp.main:app --host 127.0.0.1 --port 5201`；前端在 `webfrontend` 执行 `npm run dev`，或构建后访问 `/app/`。对话应用接口放在 backend，FastAPI 启动入口仍是 webapp，避免重复通信层。

验收覆盖全部原设置页签、实际对话请求与 501、设置刷新恢复、文件上传和备份导出、开发代理、Cookie 隔离与资源边界。仓库未提供完整角色包，因此真实 Live2D 纹理与动作仍需角色包后验收；本轮在 macOS 测试，未宣称三平台或生产环境已经验证。
