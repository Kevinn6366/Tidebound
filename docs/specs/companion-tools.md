## 状态与事实来源

`storage/companion.py` 定义事实、跟进及兴趣类型。其快照作为 `RunRecord.companion_state` 随完成对话一次原子提交；执行期间只修改独立副本。下一轮及服务重启后，只从当前账号、当前时间线的 completed Run 恢复最近状态。停止、失败及最终落盘失败均不发布新状态，恢复历史不重放工具。

事实、跟进、兴趣均保存 source_run_id 与 evidence；工具参数的 source_run_id 默认 current，由后端绑定本轮实际 ID，历史原话仍须提供历史 Run ID；程序要求来源为当前轮用户正文或有效已提交轮次的用户原话，拒绝外部账号、失效来源与伪造引文。程序能验证引用存在，不能证明模型概括完全忠实；提示词要求不得把角色推测、虚构或网页内容保存成用户事实。

各类最多 50 项，超限返回工具失败，不擅自丢弃旧事实。资料在主请求及登录问候中作为 `companion_state` JSON user 资料注入，不写成 system 指令或新的持久化用户消息；规则与当前 run_id 单独注入。所有资料和工具声明纳入实际请求、空闲显示及主动/自动压缩预算。预算不足遵循现有压缩或明确失败规则。

## 回看与主动清空

`read_past_conversation` 支持关键词、run_id、分页和正文片段偏移，只返回有效已提交的用户原话、最终回复和时间。不读取工具链、reasoning_content、停止/失败记录、模型请求审计或其他时间线。每页最多五轮，每条正文片段最多 1200 字符；`next_offset` 翻页，`next_content_offset` 配合 run_id 继续读取长正文。

管理员“清空上下文”现在切换时间线、撤销并等待主 Run、取消后台压缩，然后清除该账号所有旧 Run 的用户正文、消息和陪伴状态，删除摘要版本。Run 仅留下无正文的失效墓碑，防止旧客户端 run_id 重放。其他用户及账号预算设置不受影响。失败不宣称删除成功；新时间线已不允许访问旧材料，可重试清除。

独立的管理员模型请求审计与运维日志仍按原规格保留，不属于工具可读取的对话历史。这不是账号数据全面擦除功能。自动/主动**压缩**仍保留原文，仅主动**清空**删除历史；删除上下文与回退不是同一操作。

## 跟进工作流

主 Agent 根据对话选择工具。创建、更新和取消工具内部先进入 `workflows/followup/N01-Summarize.py`：加载专用提示词、输入操作/原话/原事项 → 一次无工具模型调用 → 校验正常终止、JSON、摘要和条件长度 → 工具入口暂存对应状态。工作流不能自行改变调用方选定的操作或目标事项；取消始终写 cancelled。创建相同来源/引文的活动事项保持幂等。

提示词位于 `prompts/master/workflow.followup/`，常驻简短行为规则位于 `prompts/master/companion.rules/`。摘要调用复用主模型与本轮预算、超时，Console 以 `purpose=workflow.followup` 标识。摘要流不显示在用户回复预览。活动、完成、取消状态均可查；取消记录作为后续不再主动提及的边界。不会承诺到点提醒或主动联系。

## 联网与现实信息

模型指定的网页读取只允许标准端口 HTTP/HTTPS，拒绝 URL 凭据及控制字符。逐跳 DNS 检查全部地址，拒绝私网、环回、链路本地等非公网地址；连接固定已验证 IP，HTTPS 保持原域名证书校验，避免校验后重新解析。最多三次重定向，不向重定向目标转发 API 凭据，不使用进程代理、Cookie 或浏览器登录态。响应最多 512 KB，有连接和读取超时；不运行脚本，不下载子资源，仅接受文本网页，正文最多 6000 字符并标记截断。外部内容不可信，不提升权限。

天气要求明确地点；地名有多个候选时先返回名称、地区与坐标，不静默选取第一个。确认坐标后返回当前及三天天气、单位、时区和来源。地点不存在或失败不会伪造天气。

兴趣保存需要用户原话；检查仅查询指定的已保存兴趣。成功查询后暂存已见 URL（最多 100 条）及时间，随主 Run 完成提交；失败不推进。结果表示新见搜索条目，不保证事件刚刚发生，也不保证任意长期范围内绝不重复。分享时机交由主 Agent，未建立定时任务。

## 搜索的两段独立流式呈现（2026-09-19）

主 Agent 决定搜索后，搜索工作流先执行 `N00-FirstReaction.py`（`tools.websearch.reaction`）。节点只输入当前问题和已选主题，理解问题后直接流式输出一句亚托莉的第一反应；不等完整 JSON 后再展示，不包含检索结论、过程播报或未证实的新事实。节点继续使用独立硅基流动 DeepSeek V4 Flash，无工具权限；最多 80 字符、首个正文分片最多等待 5 秒，首字到达后最多再等待 15 秒完成，失败记录事件并撤回未完成首段，继续正式检索。同一 Run 仅尝试一次。

首段完成后保持显示，后台依次执行原有完整语境概括、博查检索、阅读印象。主模型收到 `spoken_reaction` 并由尾部提示词要求自然续答，随后开始第二段独立流式输出，不把首段反复拼在第二段分片前。`preview_stage` 区分 reaction/answer，两段展示身份不同；第二段到达时重置剧情页和打字机，避免停在首段分页。内部整理节点仍不向页面泄露 JSON 或思考。

两段仅在整轮完成后进入正式剧情历史，以两条角色消息展示；运行时保持同一 Run 和合并的规范回复，兼容现有历史回忆、压缩及提交边界，首段元数据用于还原展示。第一反应与最终回复分别记录展示时间；停止、失败或旧时间线不能把首段独立提交成成功回复。主动清空同时清除第一反应正文和显示元数据。SSE 连接继续传输有阶段标识的状态快照，断线重连不会重放模型或重复追加消息。
