# Tidebound v0.02

发布分支：`dev`。Python、WebApp 和前端包版本为 `0.0.2`。

本版加入工具调用后的一次性提示词注入、按对话轮次分组的完整 LLM 请求 Console、流式回复、上下文预算圆环和管理员 Dev 工具箱的上下文重置。

认证、密码验证、登录会话与 HTTP 权限代码统一位于 `webapp/auth/`。后端重启导致会话失效时，私有 API 返回 HTTP 401；用户页面跳转登录，已经打开的聊天和 Console 也在收到 401 后回到登录页。账号与历史数据保留，登录错误在表单内显示，权限不足继续返回 403。

当前仍为单进程、单 worker 本地 dev，运行方式见 [账号与 Console 规格](../specs/accounts-and-console.md)。
