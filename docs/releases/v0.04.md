# Tidebound v0.04

产品版本为 `0.04`，Python、FastAPI 与前端包版本为 `0.0.4`。本次将 dev 累积改动合入 main，仍采用单机、单 worker 开发运行方式。

## 主要变化

- 接入历史回看、事实记录、跟进事项与摘要工作流，以及联网权限控制下的搜索、网页、天气和兴趣更新能力。
- 搜索采用先接话、后续答的两段流式呈现；正式续答保留统一角色设定和有效对话语境，临时表达规则不写入历史。
- 增加独立登录欢迎工作流、固定世界观与角色表达优化；精简角色提示词，明确话题边界、原作资料与共同经历的区别。
- 完善 Console 的模型请求、运行日志、工具和工作流展示，支持主聊天渠道切换及开发环境免密码调试。
- 同步上游前端增量。TTS 等设置入口的保留不表示语音服务已接入。
- 新增项目 README、详细目录职责、快速开始与 Future 清单，并记录两轮真实 Chrome 闲聊评估。

## 验证

- Python 测试：185 项通过。
- Ruff、前端 ESLint、TypeScript 检查与生产构建通过。
- 新版角色提示词通过 Chrome 新账号连续 15 轮普通聊天验证；该轮未覆盖联网和压缩，不代表全部行为问题已消除。

当前仍有测试依赖弃用提示和前端构建包体积提示。聊天中轻松表达的叫停、关心后的过多安排仍是体验改进方向。完整长期记忆检索、主动通知、语音及多 Agent 协作等规划见 README 与 Future 文档。
