# 后续能力

依据 [宏观架构规格](specs/architecture.md)，以下能力放入 Future，不作为当前主线的启动或实现前提：

- TTS、口型、角色动作、语音输入。
- 多 Agent 协作。
- 独立 App 形态。

这些能力进入具体迭代时，再编写对应专项规格与实现。上游已有相关资源可以保留，其存在不表示 Tidebound 已完成接入。

Python 代码生成仍是计划中的工作流能力，生成结果是否执行尚未确定，不能据此开放任意代码执行。独立世界模拟器不属于当前产品范围；当前也不引入分布式基础设施或通用插件平台。
